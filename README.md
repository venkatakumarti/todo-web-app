# To-Do List Web App 📝

This is a simple To-Do List app built using HTML, CSS, and JavaScript. You can add tasks, mark them as complete, and delete them. Tasks are saved using localStorage, so they stay even after you refresh the page.

## 🚀 Features

- Add new tasks
- Mark tasks as completed (click on task)
- Delete tasks (click ❌)
- Tasks persist in browser using localStorage

## 🖥 How to Use

1. Clone or download this repository
2. Open `index.html` in your browser
3. Start adding tasks!

## 🛠 Technologies Used

- HTML
- CSS
- JavaScript (Vanilla)
- localStorage
